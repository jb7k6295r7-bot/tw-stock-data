### 1-2 ⛔⛔ 240MA 的窗口坑：**a 一律分段報，主判定用 2001 起**

```
資料庫線 2120 實測：240 個交易日

⇒ ⛔「240MA ＝ 年線」只在 2001 之後成立
⇒ 跨那條線比較，比到的有一部分是【窗口長度】不是【市場行為】
```

**⇒ 裁定（K線分析線 0800 §末）**：

```
✅ a 一律【分段報】：1990s 那 12 段另報、⛔ 不與後面合併
✅ 主判定用【2001 起】：去抖段 27 ⇒ n = 26，仍過 24
⛔ 不為此改 240MA 的單位 —— 改了會與 skill 裡所有 240MA 口徑分岔

```

### 1-3 ⭐ K = 20 **交易日**維持（⛔ 不改日曆天）

```
理由（K線分析線 0800）：摩擦以【交易次數】計，不是日曆天
佐證：日曆天版與交易日版在 a 上都給 39（39 對 39）⇒ 不敏感
⚠ 資料庫線 2120：K=20 交易日在 1990 年代 ＝ 24 日曆天、2001 後 ＝ 28 日曆天
⇒ 這個不一致要寫進限制欄，⛔ 不用改定義去消除它
```

### 1-4 去抖的逐行機器定義（⛔ 三個邊界，回測線實作已對過）

```
輸入　逐日狀態序列 s[t]（離散），NaN 先丟掉　｜　K = 20 交易日（⛔ 事前寫死）
① 切段：切成連續同狀態的區段 [(state, len), ...]
② 併入：由左到右【掃一次】
 若 該段 < K 且【不是第一段】⇒ 併入前一段，⭐ 狀態取【前一段】的
 否則 ⇒ 另起一段
 ⛔ 邊界一：第一段不論多短一律保留
 ⛔ 邊界二：⭐【單次掃描，不重掃】—— 併出的新段不再回頭檢查長度
③ 合併：把相鄰且同狀態的段合併
④ 有效 n ＝ 合併後段數 − 1
```

## 二、題目的正確名字

⛔ 不是「預測大盤會怎麼走」。✅ 是：

> **「用當期就看得到的市場狀態決定投入多少錢，會不會比固定投入好。」**

```
市場訊號只決定【部位大小】，⛔ 不決定【買哪一檔】
⇒ 與選股完全可分離 ⇒ 選股結論不受污染；訊號對不對只影響曝險
```

### 2-1 ⭐ 它是 PREREGP1「28% 現金」那個混淆的正面版本

```
PREREGP1 量到：贏過 0050 的兩格，槽位使用率僅 81.5%／71.6%
⇒ 28% 資金空手，在 2020 那段自動少跌 ⇒「贏」可能是現金買的
⇒ ⭐ 本題問：那 28% 現金能不能【有意識地、在對的時候】留？
```

### 2-2 ⭐⭐ 它與 PREREGP4 是同一個問題的兩個軸（0815 §1-2）

```
M1 決定【總曝險】　　　P4 的 N 決定【怎麼切】
⇒ 兩者【相乘】才是「每檔分到多少錢」，而那才是使用者真正在問的
⇒ ⛔ 兩題的結論不該各自獨立出，要能相乘
```

## 三、層一：狀態 → 未來大盤報酬

```
序列　data/history/market_index.csv 的 close，1990-01-04 起
 ⛔ change 欄留空、change_pct 不帶號 ⇒ 一律不讀，要漲跌自己從 close 算
訊號（⛔ 全部事前寫死、全部當期可得，⛔ 不可跑完再挑）
 a 收盤 vs 240MA（在上／在下）　　　⇒ ⛔ 分段報，主判定 2001 起
 b 近 60 日報酬（正／負）
 c 20 日實現波動率的 500 日歷史分位（>70 高／30~70 中／<30 低）
 d 月線方向（月收盤 > 前月收盤），日展開
 a∧b 三態（同向多／同向空／不同向）⇒ 對應三檔位
量測　各狀態下【未來 20／60／120 日】指數報酬的分佈
必報　平均、p05/p10/p50/p90/p95、該狀態的【去抖後區段數】、以及【逐段勝率】
⛔ 比價基準：層一是【同一條指數各狀態互比】⇒ 不需要含息報酬指數
 ⭐ 因為「不含息」的缺漏對每一個狀態都一樣 ⇒ 狀態之間的差值無偏
```

### 3-1 ⚠ 但除息季節性要查（策略線 2026 §一 提的殘留）

```
台股除息集中 7~9 月 ⇒ 價格指數那一段會系統性被壓低
⇒「缺漏對每個狀態都一樣」只在【各狀態月份分佈相近】時成立
✅ 回測線 2047 已一次性量過：240MA「下」狀態在 7~9 月只占 14%（偏斜存在）
 影響 ≤ 0.4pp ⇒ ⭐ 不足以翻轉任何結論
⇒ 仍必報：① 各狀態的進場月份分佈（12 格）② 剔除 7~9 月進場的敏感度版本
```

### 3-2 ⭐ 股息拖累：**關掉，但量測結果要寫進限制欄**

```
回測線 2047 §二實測：
 第一版把 0050 的 2025 分割當成股息 ⇒ 下修 11.65pp　⛔ 這個錯法要記進限制欄
 第二版只用息因子 ⇒ 狀態間差【最大 0.39pp】
⇒ ✅ 關掉股息調整（差異小於成本錨 0.585%）
⛔ 但不可只寫「關掉」—— 要寫「量過、差 0.39pp、所以關掉」
```

### 3-3 否證／出口

```
① 該訊號（或該狀態）的去抖後 n < 24 ⇒ 標【還沒測】，⛔ 不進判定、不觸發撤除
② n ≥ 24 且兩狀態的未來報酬差的 95% CI 含 0 ⇒ 該訊號【測不出】
③ ⛔ 若五個訊號全部測不出 ⇒ 層二不跑
④ ⭐ 若只有 d（月線方向）測得出 ⇒ ⚠ 層二仍不跑：d 有一個月的延遲且素切換 219 次最抖，
 單靠它支撐一整套部位規模規則，證據不足
```

### 3-4 多重檢定

```
5 訊號 ×（2 或 3 狀態）× 3 持有期 ＝ 39 格
⛔ 而分段報（4 個年代）會讓格數再乘 4 ⇒ 156 格，虛無期望 ≈ 7.8 格
⇒ ⛔ 判定只用【c 與 d 的 H=120 全期】＋【a 的 H=120 2001 起】＝ 8 格，虛無期望 0.4
⇒ 其餘（分段、b、a∧b、H=20/60）一律只能寫「方向一致／不一致」
```

## 四、層二：狀態 → 檔位 → 組合層

⛔ **層二期間維持 2015-01 ~ 2026-03**（個股母體限制），⚠ 與層一期間不同，結果檔必須分開標。

### 4-1 檔位映射（⛔ 事前寫死）

```
大跌 40%　跌 60%　盤整 78%　漲 90%　大漲 100%
```

⚠ **「盤整 78%」的來源要標清楚（v1 標得不夠）**：
```
使用者原話「盤整走勢，就是一般金額(含保留現金)」⇒ ⭐ 基準線【本來就不是滿倉】，這是他的
⛔ 而【78% 這個數字】是我方訂的（取自 PREREGP1 實測的槽位使用率量級）
⇒ 兩件事要分開標（〈三十九〉）
⇒ ⛔ 對照組不可只拿 100% 滿倉當唯一基準
```

### 4-2 不對稱門檻（⛔ 事前設計，不是跑完調的）

```
⛔ 錯誤的方向不對稱：選錯一檔虧那一檔；【在大跌前加大部位，虧的是全部】
降低：狀態轉為【不利】當月即降
加大：狀態須連續【兩個量測月】維持有利才加
```

### 4-3 ⭐⭐⭐ 三個對照組（⛔ ② 是必備）

```
對照① 固定滿倉 100%
對照② ⭐【同平均曝險、時點隨機】：算出③的平均曝險，隨機決定哪些月降／哪些月加，
 保持平均曝險相同、只打亂時點，重抽 200 次取分佈
對照③ 照訊號調整檔位（待測）
⛔ ③ 要贏，必須贏過 ② 的【分佈】，⛔ 不是贏過 ①
```

> ⛔ 少了②，「回落比較小」分不出是【擇時對】還是【單純持股較少】。
> ⚠ 而 PREREGP1 已證明這個混淆會真的發生。

### 4-4 主要測量與必報

```
主要　最大回落 ＋ 年化，⛔ 兩個都要
必報　⭐【訊號錯的時候的機會成本】—— 在漲勢中降低檔位，少賺了多少
 ⛔ 只報「回落變小」而不報這個，等於只報保險的理賠、不報保費
必報　③ 相對 ② 的分佈位置（百分位），⛔ 不是只報「③ > ①」
必報　各狀態的實際停留月數與該狀態下的實際曝險
```
