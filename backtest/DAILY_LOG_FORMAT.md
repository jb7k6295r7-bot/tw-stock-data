# 每日選股逐日留檔格式（回測線提議，2026-09-09；給市場情報分析線實作）

目的：讓「報告推薦的那些檔，20／60 日後真的如何」可以事後對答案。三條約束照情報分析 09:55：一天一檔、當天寫完不再改；每列答得出「哪天算、用哪天以前的資料」；被排除的也留、帶原因碼。

## 一天三個檔（都放 `daily_log/YYYY-MM-DD/`，CSV、UTF-8、表頭固定）

### 1. `universe.csv` — 當日母體（每檔一列，**通過與未通過都在**）

| 欄 | 型別 | 說明 |
|---|---|---|
| `asof` | 日期 | 算這一列用的最後一個資料日（＝ T−1 收盤；報告日若是 T 早上，asof ＝ 前一交易日） |
| `stock_id` | 文字 | 代號（保留前導零） |
| `market` | 文字 | twse／tpex |
| `amt_ma20` | 數值 | T−20～T−1 成交金額算術平均（元），沒成交記 0 一起平均 |
| `liq_pass` | 0/1 | `amt_ma20 ≥ 50,000,000` |
| `gate_pass` | 0/1 | 全部閘門通過（進推薦母體） |
| `excl_code` | 文字 | 未通過時的**第一個**原因碼（見下表）；通過寫空 |
| `excl_detail` | 文字 | 原因的數字（例：`breakpoint:2026-08-10`、`missing:3/20`、`disposal:2026-09-01~2026-09-12`） |

原因碼（固定字串，方便 groupby）：`liq`（流動性）、`missing`（近 20 日缺漏）、`breakpoint`（斷點窗內）、`disposal`（處置）、`attention`（注意股，若有排除）、`esb`（興櫃）、`margin_stop`（停止融資融券，只影響籌碼層時**不排除**，這碼給「整檔不判讀」的情形用）、`other`。
排除順序照 K線線 08:40 裁定：興櫃 → 硬斷點 → 近期缺漏 → 其餘；只記最上游那一個。

### 2. `picks.csv` — 當日推薦與評分（每檔一列，**含被評分但沒進前 3 的**）

| 欄 | 說明 |
|---|---|
| `asof` | 同上 |
| `stock_id` | 代號 |
| `rank` | 名次（1 起） |
| `recommended` | 0/1（有沒有進報告的推薦） |
| `score` | 評分（數值；沒有評分就留空，不要編） |
| `signal_codes` | 命中的條件碼，以 `;` 分隔（例：`rev_hi24;bull_ma`） |
| `entry_ref` | 報告寫的參考進場價（沒有就空） |
| `stop_ref` | 警戒價／停損價 |
| `target_ref` | 目標價（沒有就空） |
| `horizon_days` | 報告預設的持有期（20／60） |
| `note` | 一句話（可空） |

### 3. `holdings.csv` — 關注持股當日狀態（每檔一列）

| 欄 | 說明 |
|---|---|
| `asof` | 同上 |
| `stock_id` | 代號 |
| `since` | 加入日期 |
| `status` | `ok`／`warn`／`not_applicable`（序列有斷點、預計出窗日寫在 `detail`） |
| `stop_ref` | 當日警戒價（不適用時空） |
| `detail` | 例：`breakpoint:2026-08-10;resume:2027-08-03` |

## 規矩

1. 檔案寫完就不改；要更正就在**當天新開** `picks.v2.csv` 並在第一列註明取代誰（`superseded_by` 不用欄，用檔名）。
2. 所有價位是**未還原價**（報告用的就是未還原價；回測對答案時我自己還原）。
3. 對答案時回測線只讀這三個檔，不讀報告內文；報告內文與這三檔不一致時，以這三檔為準並回報差異。
4. 第一天上線後回測線會讀一次回報「欄位讀得到、能對到 `data/stocks/`」，之後每週對一次。

## 回測線會拿它做什麼

- 命中率研究：`recommended=1` 的檔 20／60 日後的淨報酬對「同日 `gate_pass=1` 母體」的超額；被排除的檔同樣算（看排除有沒有排到該排的）。
- 閘門稽核：每日 `gate_pass` 檔數的時間序列（K線線 12:10 問的「N 有沒有被檢查」的資料來源）。
