## 二、引擎（`research11.simulate_mtm` 加參數，⛔ 預設值下行為與現行**逐位元相同**）

新參數（全部有預設，預設＝現行）：
- `d_max`（None＝∞）：同一個 t 最多新增 d 個部位。
- `pick`（None＝現行 `rng.permutation`）：`"relvol"` ＝ 候選依 **相對量能** 遞減排序（訊號日成交金額 ÷ 該檔前 60 個交易日成交金額中位數；由 `load_bars` 的 `amt` 算，前 60 根不足 ⇒ NaN 排最後）。⛔ 不用 `liq`（那是前 20 日均值）。

- `queue_days`（0＝不排隊）：被 (b) 擋掉的訊號留在隊列最多 Q 個交易日，之後每天再試（仍受槽與 d 限制）；進場價＝**實際進場日**的還原 open、出場日**不變**（原 `xpos`，持有變短）、gross 重算＝`closes[exit]/open[t′] − 1`；Q 天內沒進到 ⇒ `b_expired`。**Q＝5，回測線定的**（登錄 4-B 要「推遲的中位天數」，沒有隊列就沒有推遲；5 ＝ 一週）。⚠ (a) 槽滿的不排隊（現行行為：當天沒進就丟）。
- 擋掉原因的判定（回測線定的）：`slots_free = N − 持倉數`、`d_free = d − 今日已新增`；候選數 > `min(slots_free, d_free)` 時，多出來的標 **a**（若 `slots_free ≤ d_free`）或 **b**（否則）；cash 用盡視同 a。

## 四、先驗（策略線登錄五節，逐字抄；⛔ 跑完不改）

① N 40→2 年化中位下降、離散度放大（N＝3 約 25～30 pp、N＝2 約 30～35 pp）；② N ≤ 8 沒有一格過三條判準；③ d ∞→1 年化中位與槽位使用率下降，但降幅 < 把 N 從 8 降到 3；④ 擋掉組 vs 進場組：null 下 CI 含 0（引擎 sanity）、R1 下也含 0；⑤ 做 m 筆真實機率低於 89%，N＝3 時押 70～85%。
回測線的事前預期（本線補）：小 N 下 (c)「已持有」那層會占擋掉組的大宗（訊號同一檔常連續出現），排除 (c) 之後 a／b 兩層 n 會小很多；R1 與 null 的存量曲線差 CI 含 0；隊列讓 d＝1 的 `b_expired` 在 AND 上 < 10%（AND 每月中位 14 筆、槽 8，擋得少）。

## 五、否證條件（策略線六節逐字，加 K線分析 ③）

① null 下、**排除 (c) 後**擋掉組仍顯著優於進場組 ⇒ 引擎有偏誤，先查引擎、不寫成結論；② R1 − null 存量曲線差 CI 全含 0 ⇒ 只能寫「挑選規則測不出差異」；③ N ≤ 8 有一格過三條判準 ⇒ 反駁先驗②，據實報；④ 22 格只測得出 1 格 ⇒ 等於雜訊期望，判「測不出」。
判定用語：統計層 測得出／測不出；可執行層 扣成本後剩 X pp／不可執行；「通過／顯著／有效」停用。零／n_min／出口照 K線分析 0715 三節：「零」＝主 CI 含 0 ∧ |點估計| ≤ 0.585%；n_min＝月分群有效月數 ≥ 24（每格附有效月數）。
