# 丙、PREREGP3：閒置資金放 0050 vs 空手

```
✅ 值得，⭐ 而且我認為是【最高優先】：

② ⭐⭐ M1 層一把另一條路關掉了 ⇒ 本件是唯一還能分辨甲乙的路

⛔ 它【不能】給什麼：只分辨「贏是不是現金買的」，⛔ 不回答「該不該持有現金」
```

## 一、假說

```
H1　閒置槽位的資金改放 0050（cash_mode="bench"）之後，那三個「贏過 0050」的格子【不再贏】
 判準：該格的最大回落中位【劣於或等於】0050 買進持有
H2　N ≤ 8 的 16 格，在 bench 下仍然沒有一格贏（⭐ 負向假說，確認改動沒引入別的東西）
```

⚠ **方向來源**：H1 來自策略線 09-14 對槽位使用率的觀察，
⛔ **不是從 bench 版結果讀來的（那個結果還不存在）** ⇒ ✅ **這一份是真正的前瞻登錄。**

## 二、否證條件

```
H1 否證　三格在 bench 版【仍然贏】⇒ ⭐ 那表示「贏」不是現金買的，P1 的結論站得住
H2 否證　N ≤ 8 出現任何一格贏 ⇒ ⛔ 改動引入非預期效果，本件作廢重查
整體出口　ⓐ 有效月數 < 24 ⇒ 還沒測
 ⓑ bench 與 cash 的差異 p10~p90 完全重疊 ⇒ ⭐【分不出】（合法結論，⛔ 不是失敗）
```

## 三、⭐⭐ 三個對照組（⛔ 缺一不可）

```
甲　cash_mode="cash"　閒置槽位空手（＝現況）
乙　cash_mode="bench" 閒置槽位放 0050，⭐ 單邊成本 COST/2 進出各一次
丙　⭐⭐【同平均曝險、時點隨機】：保持與甲相同的平均槽位使用率，
 但把「哪幾天空手」隨機打散，重抽 200 次
```

> ⛔ **丙是本件的核心，不是選配。** 沒有丙，分不出「甲贏」是【時點剛好對】還是【單純持股少】。
