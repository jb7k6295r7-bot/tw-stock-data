## 一、機器定義 → 程式（`backtest/wsh.py`，自測 12 條、突變 5 個全抓到）

| 條文 | 程式 |
|---|---|
| swing high／low（0947 逐字，k＝5） | `swings()`：high[i] 嚴格大於前後各 5 根；確認日 i+5 |
| 末跌高＝下降趨勢裡最後一個較低高點；移動狀態機（0925 三①） | 每一次**更低低點** L 確認：末跌高 := L 之前最近的 swing high（反彈沒破 ⇒ 往下移；破了又再破底 ⇒ 往上移，同一條規則）；較高低點不改結構 |
| 下降趨勢的最低要求（我方補） | L < 前一個 swing low **且** 末跌高 < 它之前的 swing high（LL＋LH） |
| 第一步：突破末跌高 | 收盤 > 末跌高（E0，水平線）；每個末跌高只准觸發一次（武裝／解除） |
| 第二步：打底不再破底 | 第一步**之後**第一個 swing low 確認且 ≥ L ⇒ HL；確認前收盤 < L ⇒ 回到狀態 0 |
| 第三步：突破前高 H | H ＝ 第一步到 HL 之間的最高 high；收盤 > H ⇒ **訊號日**；進場 ＝ 次一有效 K 棒開盤（研究十五 P1 口徑） |
| 放棄（0925 二）：三部曲沒完成 | ABANDON ＝ HL 成立後收盤 < HL；NOSTEP3 ＝ 第一步後 60 根內沒走到第三步（⚠ 60 是我方定的） |
| 對照組②（比照研究十五）：第一步就進 | S1 ＝ 第一步當根為訊號日、次根開盤進 |
