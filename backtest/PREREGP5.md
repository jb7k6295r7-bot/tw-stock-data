# 己、PREREGP5：四型的組合層（軸＝每檔金額，指標＝右尾實現率）

⛔ **前置：必須等你們用 `p4_centroids_v3.json` 獨立覆核 P4 主格數字之後才跑**
（門檻：分位數差 ≤1.0pp、超額差 ≤0.3pp）

## 〇、值不值得做 —— 它是「研究結論」接到「實際做法」的那一步

```
P4 的 ①+4.88pp、②+2.98pp ⛔ 完全來自右尾（p90 +61.0%，逐筆中位 −5.19%，逐筆勝率 41.9%）
⇒ ⭐⭐ 靠右尾支撐的分佈，能不能實現，強烈取決於【同時抱幾檔】
⇒ 抱太少 ⇒ 抽不到右尾 ⇒ 實際拿到的遠低於 +4.88pp
⇒ ⭐ 本件回答：「這套東西要同時抱幾檔，才拿得到那 +4.88pp」
⛔ 這一步不做，P4 前面全部白做
```

⛔ **軸是【每檔金額】不是【檔數】**（使用者 09-15 訂正：每日 3 檔是報告產能限制）
⇒ **通則：我方的限制屬於交付計畫，⛔ 不屬於研究設計。**

## 一、假說

```
H1　①型的組合層超額隨 N 上升而收斂，且存在 N* 使【右尾實現率 ≥ 0.9】
H2　N = 8~10（使用者裁定目標）時，①型的組合層超額 CI 不含 0
H3　⭐「排除④死水」版在 N = 8~10 時 CI 不含 0
 （先驗上比 H2 容易成立 —— 排除不依賴右尾）
```

⚠ **方向來源**：H1/H2/H3 都來自 P4 已產生的數字 ⇒ ⛔ **不是前瞻**
⇒ ⭐ **本件與 P4v3 同屬「訂正後的回溯分析」，⛔ 不得寫成前瞻驗證。**

## 二、否證條件

```
H1 否證　N 到 30 為止右尾實現率仍 < 0.9
 ⇒ ⭐ 結論是「這套東西要抱 30 檔以上才拿得到」
 ⚠ 那與 8~10 檔目標【衝突】⇒ 是要報上去的取捨，⛔ 不是失敗
H2 否證　N = 8~10 時 CI 含 0
 ⇒ ⛔⛔ 那表示 +4.88pp 在使用者實際會做的規模上【拿不到】
 ⇒ ⭐ 這一句必須寫進 CONCLUSIONS，⛔ 不可只留在資料裡
H3 否證　排除④版在 N = 8~10 時 CI 含 0
整體出口　有效月數 < 24 ⇒ 還沒測
```

## 三、量測

```
訊號集（三個，各自獨立跑）
 (a) P4 的 ①型　(b) P4 的 ②型　(c) ⭐ 全母體【剔除④死水型】
N　3 / 5 / 8 / 10 / 15 / 30　⛔ 上界由工具能力定，⛔ 不由「3 檔」定
H　120（主判定）／60　｜　主格 2021-01~2026-03；副格 2017-01~2024-12
工具　⛔ 沿用 P1 的組合層引擎（simulate_mtm），⛔ 不另寫
```

### 3-1 ⭐⭐ 新指標：右尾實現率

```
右尾實現率 ＝ 組合層拿到的超額 ÷ 該型的逐筆平均超額
⇒ 這個比值隨 N 收斂到 1 的那個 N，就是「右尾抽穩了」的 N
⭐ 那個收斂點是一個【輸出】，⛔ 不是限制
```

### 3-2 ⛔⛔ 基準必須是「同 N 的隨機選股」，不是 0050

```
K線分析線的分散曲線（47 季全市場快照）
 N=1 p50 −0.9%　p90 +42.9%　離散度 1.00　虧損機率 51.4%
 N=3 p50 +1.6%　p90 +34.2%　離散度 0.66　虧損機率 46.4%
 N=8 p50 +3.5%　p90 +29.2%　離散度 0.51　虧損機率 41.3%
 N=15 p50 +4.2%　p90 +26.8%　離散度 0.46　虧損機率 38.2%
 N=30 p50 +4.6%　p90 +25.3%　離散度 0.42　虧損機率 35.3%
⛔ 訊號集的超額是【疊在這條曲線上】，不是取代它
⚠ 該曲線的【絕對水準不可引用】（未還原價），只有比值與形狀可引用
```

### 3-3 必報

```
① 每格：年化中位、離散度 p10~p90、⭐ 右尾實現率、逐筆勝率、月勝率
② ⭐ 與同 N 隨機選股的差（＝真正的選股超額）
③ 槽位使用率
④ ⛔ 每檔金額佔比（＝1/N）與現行單一部位上限 20% 的關係
 （P1 已知：等權下要滿足 20%，存量必須 ≥ 5 ⇒ N=3 會違反）
⑤ 母類股 ≤2 的可行性：⚠ ①型有 12.6% 的月份湊不滿 8 檔（本線實測）
 ⇒ ⭐ 請一併報「因類股上限而少持有幾檔」
```
