## 對帳（`_check.py`）

抽 10 檔（2330、8299、3661、4971、3718、4573、1623、3289、2464、6669），**不 import 本程式／research34／data**，從原始 CSV 另寫一條路：月營收逐檔讀 revenue_hist、季報讀 fs_hist 原檔相減、存貨讀 fs_xbrl、還原因子用 adj 的 `factor` 欄自己連乘（不用 cum_factor）、本益比讀 stocks_per、名單讀 daily md。
結果 **160 項全部相符**；另 19 項交叉（fs_hist 營業成本 vs fin_hist 營收−毛利）全部在 0.5% 內：8299 差 0.13%／0.35%、2464 差 0.14%，其餘 0（其中 3718〔5371〕2 項、4573 1 項 fs_hist 沒有、兩邊同為 fin_hist，屬同源不算獨立）。
