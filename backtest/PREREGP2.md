# 戊、PREREGP2：類股集中度上限的成本（主要測量改為**最大回落**）

## 〇、值不值得做

```
✅ 值得，但【價值比我 09-14 認為的小】，理由先講：
 母類股 ≤2 在全母體上的持有上限【中位 50 檔】⇒ ⛔ 對 8~10 檔而言幾乎不咬
 ⇒ 本件不是「這條規則讓我少賺多少」，而是【它有沒有換到該換的東西】
⭐ 真正值得測的是那個交換：
 類股上限的目的是【降低同時下跌的機率】⇒ ⛔ 主要測量必須是【最大回落】
 用年化去測它，會得到「限制越多賺越少」這種廢話
```

## 一、假說

```
H1　拿掉母類股 ≤2 之後，最大回落中位【變深】且 CI 不含 0 ⇒ ⭐ 規則有在做事
H2　拿掉之後年化中位【不顯著變好】（CI 含 0 或改善 ≤ 0.585%）⇒ ⭐ 成本很低
⇒ H1 ∧ H2 同時成立 ＝ 這條規則【划算】
```

⚠ **方向來源**：從規則的**設計目的**推的，⛔ 不是從任何已產生的數字讀的 ⇒ ✅ 真正的前瞻登錄。

## 二、否證條件

```
H1 否證　最大回落【沒有變深】或 CI 含 0 ⇒ ⛔ 規則沒換到東西（放不放由使用者裁）
H2 否證　年化顯著變好（>0.585% 且 CI 不含 0）⇒ ⚠ 成本不低，要與 H1 的收益權衡
整體出口　ⓐ 有效月數 < 24 ⇒ 還沒測
 ⓑ ⭐「有／無上限」兩版組合重疊度 > 90% ⇒ 規則根本沒觸發
 ⇒ 寫「這條規則在本母體上幾乎不咬」，⛔ 不寫「無效」
```

## 三、量測

```
母體與訊號　沿用 P1 的 AND 集合與網格（⭐ 要能與 P1 逐格對帳）
產業別　⭐ 逐期面板，取量測日前兩個月可得的最近一期 ⇒ ⛔ 無前視
 ⛔⛔ 不得使用 industry.csv 的現在快照（第十八條）
母類股　（定義同「乙」節）
 ⭐ KY 股（無產業別）＝【單獨一組】，⛔ 不可歸「其他」也不可丟掉
對照　甲 有上限（子類股≤2 ＋ 母類股≤2）　乙 無上限　丙 ⭐ 只有母類股≤2（拆開看貢獻）
主要測量　⭐【最大回落中位】＋ p10~p90　｜　次要：年化中位
必報　① 規則【觸發率】：每月幾檔被擋
 ② 被擋掉那些的【後續報酬】（第十九條）
 ③ ⭐ 與同 N 隨機選股比　④ 槽位使用率　⑤ KY／無產業別組的檔數與佔比
多重檢定　3 × N∈{5,8,10} × H∈{60,120} = 18 格，虛無期望 0.9
 ⛔ 判定只用 H=120、N=8 的 3 格
```

## 四、⛔ 限制

```
⛔ ① 前置的「上限」是理論上界（2×母類股數）⇒ 樂觀
⛔ ② 覆蓋率 86~95%，缺的集中在 KY 股 ⇒ ⚠ 那一組的內部相關性未知
 ⇒ 當成一個母類股，可能高估也可能低估集中度
⛔ ③ 期間沿用 P1 ⇒ 不含 2008／2000
 ⚠⚠ 而類股集中度的風險【正是在系統性下跌時最大】
 ⇒ ⭐ 這是本件最嚴重的限制，要寫在結論第一段
⚠ ④ 不含現金曝險分離 ⇒ 若 P3 先出，一併跑 bench 版
```
