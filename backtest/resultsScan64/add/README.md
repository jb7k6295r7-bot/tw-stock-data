## 做法（同 64 格的橫斷面）
- 形成月最後交易日（量測日）算因子 → 下一交易日收盤買 → 下月最後交易日收盤賣；還原價；窗內壞根作廢（前組、母體對稱）。
- 前五分之一（取高）− 同月母體等權＝月超額；Q1−Q5；IC（Spearman）；換手；扣「換手×0.585%」。
- 分段以持有月：探索 2017-03～2021-12、確認 2022-01～2026-08；可用月＝有值 ≥50 檔。
- 循環區塊自助法 6 個月、4,000 次、seed 5。Bonferroni 依 seq526：**0.05/68 與 0.05/69 並列**（新格數 4 或 5 未定；本三格都是橫斷面，沒有多持有期乘法；同族事件格的對應門檻為 0.05/204、0.05/207）。

## S87 假訊號臂兩段 95% 都不含 0 的原因（seq527 二；只讀程式與既有輸出、只算不含報酬的組成描述）
- 64 格與本件的假訊號（returns.py／returns_add.py `shuffle_V`）：每個因子各自 `default_rng(5)`，逐個形成月在「當月母體內、該因子有值」的股票之間把因子值隨機重排一次（二元因子保留成立檔數），再照真因子同法取前五分之一、對同月全母體等權量月超額；整段只抽一次。所以假訊號前組＝每月從有值母體中均勻隨機抽的約 20%，與因子值、報酬都無關。
- S87 有沒有機制性理由：S87 在母體內缺值檔數每月中位 0（兩段），假訊號前組就是全母體的均勻隨機 20%，抽樣沒有不對稱；逐月重建的假訊號前組（檔數與 monthly/S87_shuffle.csv 逐月一致）跟母體的組成相同：log10 市值中位 9.92 對 9.93（探索）、10.006 對 10.006（確認），股價中位 39.5 對 40.0、56.5 對 56.3，上櫃比例 31.4% 對 31.7%、35.4% 對 35.4%，真 S87 平均 20.0 對 20.1、20.9 對 20.9（真前組是 44.9、46.0）。S29、S30 的假訊號前組也同樣貼近母體。
- 自助法區間只反映「這一次抽籤」逐月超額的波動，不含換一次抽籤的變異；64 格的橫斷面假訊號探索段也有 7／54 格 95% 不含 0（確認段 0、兩段都不含 0 的 0 格）。
- 結論：**原因未明**。程式邏輯與前組組成（市值、股價、市場別、缺值）都看不出偏向大型股或抽樣不對稱的機制；兩段都不含 0 的情形在 64 格沒出現過，照實列出，未加跑任何報酬比較。組成逐月見 shuffle_comp_add.csv。
