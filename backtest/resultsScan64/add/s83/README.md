## 定義（看結果前定）
- 每個面板有效根：市場別＝該股日線當天 market 欄。
  - 上市（twse）讀 `pricelimit/<d>.csv` 的 limit_up（＝d 當天）。
  - 上櫃（tpex）讀 `otcpricelimit/<d 的前一交易日>.csv` 的 next_limit_up。⛔ 兩支日期意義相反，照 READ_CONTRACT 文末一節。
- 漲停價 9999.95 或跌停價 0.01 ⇒ 沒有漲跌幅限制，排除、記缺值。查不到 ⇒ 不判、記缺值（另計「恢復交易首日」＝前一交易日沒有有效根）。⛔ 不推算。
- d 日漲停＝d 日收盤（未還原，日線字串轉 float64）≥ d 日官方漲停價（容差 1e-6）。
  - ⚠ 不用面板 float32 的 RC：千元價位誤差會讓「收盤＝漲停價」判錯（試算時上市、上櫃漲停根都少算約 8%，已改）。
- S83＝形成月最後交易日往回 20 根內漲停天數，有值根 ≥15；方向取高（0134 第 4 點：沒寫方向一律取高）。
  - 20 根與寫法同 64 格 S83alt／S11：`factors.roll(·, 20, "sum", 15)`。

- **跟推算口徑 S83alt 幾乎等價**：
  - 月值完全相同比例中位 100%。
  - 逐日（母體內兩者皆可判 2,350,323 根）：官方漲停 35,600 根、推算 35,443 根；推算全部包含在官方裡，只有官方的 157 根，推算缺值 59 根。
  - S83alt 在 64 格只當備註、沒跑、沒計 N，所以這不是重測已判格。
- **跟 64 格已跑的 S10 是包含關係**：S83 前組幾乎全落在 S10 前組裡（99%～100%），反過來約 7 成。Spearman 0.6～0.7，不是等價。
- 跟 S11、S02、S06 都不等價。
- 結論：不判為等價、退化。但跟 S10 高度重疊，判語時要一起講。
