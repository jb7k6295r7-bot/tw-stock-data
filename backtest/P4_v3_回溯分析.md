## 四、量測定義

```
量測日　每月第一個交易日
進場　　次一交易日開盤還原價　⛔ 無前視
出場　　H 個交易日後收盤，H = 20 / 60 / 120（判定用 H=120）
基準　　同一量測日、同一合格母體的等權平均 H 日報酬
超額　　該型當月等權平均報酬 − 同月基準
成本　　COST = 0.00585；⚠ 超額兩邊互抵不扣，絕對報酬欄另報扣成本值
離散　　月分群 SE = std(ddof=1)/sqrt(有效月數)，CI = 點估計 ± 1.96 SE
有效月　該型當月 ≥ 5 檔且基準可得
```

### 4-1 ⭐ 必報（含 0141 兩句確認的機器定義）

```
每一型 × 每一個 H × 每一個期間都要報：
 ① ⭐逐筆勝率（逐筆超額 > 0 的比例）　② 月勝率　③ 點估計超額 pp ＋ CI
 ④ ⭐逐筆超額的 p05 / p10 / p25 / p50 / p75 / p90 / p95　⛔ 四型必須【並列】報
 ⑤ 絕對平均報酬 ＋ 扣成本後　⑥ 當月平均檔數
⛔ 排序不可用單一指標：勝率／期望值／p10 三者並列
⛔⛔ ④ 必須跨型並列在同一張表 —— v2 逐型分開報，導致「四型 p10 相同」這件事
 擁有原始資料的人（策略線）自己沒看見，是 K線分析線從已報數字讀出來的
```

### 4-2 分型（⛔ 中心固定，不得重新擬合）

```
特徵 13 條（順序固定）：
 同日橫截面百分位：ret_120 ret_20 dist_hi120 dist_lo120 vol60 vr_20_120 amt20 turn20 fore20 trust20
 布林 ×100：ma_stack ma60_up rev_hi24
缺值　一律補 50
⭐ 百分位算法（0141 確認）
 pct = (嚴格小於 v 的個數) / (當日合格且該欄有限值的檔數) × 100
 ＝ np.searchsorted(sorted_x, v, side="left") / len(x) * 100
 ⭐ 同值取【最低】名次；母體含自己；該欄 NaN 的檔【不進分母】
⭐ 中心在標準化空間（0141 確認）
 C[0..3] 是 z 空間（(x−mu)/sd 之後）的中心
 ⛔ 不可把 C 反標準化回百分位空間再算距離 —— 各欄 sd 不同會改變距離排序
 歸型順序：算特徵 → 百分位／布林×100 → 缺值補 50 → z 化 → 最近中心（歐氏）
中心　KMeans(k=4, n_init=100, random_state=0)，擬合對象＝2017-2020 的贏家事件
```

### 4-3 特徵的機器定義

```
ret_120 close_t / close_{t-120} − 1（還原、ffill）
ret_20 close_t / close_{t-20} − 1
dist_hi120 close_t / max(close,120日,min_periods=60) − 1
dist_lo120 close_t / min(close,120日,min_periods=60) − 1
vol60 日報酬 60 日標準差(min_periods=30) × sqrt(245)
vr_20_120 amount 20日均 / amount 120日均
amt20 amount 20日均
turn20 volume 20日均 / 1000 / (shares_t / 1000)
fore20 foreign 20日累計 / (shares_t / 1000)
trust20 trust 20日累計 / (shares_t / 1000)
 ⭐⭐ shares_t ＝ data/stocks/<code>.csv 的【當日】shares 欄，
 依交易日曆 reindex 後【只 ffill，⛔ 不 bfill】
 ⛔⛔ 不得使用 data/meta/capital.csv（有 asof 的現在快照）⇒ 那是本庫的前視樣本
ma_stack close > MA20 > MA60 > MA120
ma60_up MA60_t > MA60_{t-20}
rev_hi24_p4 當期月營收 ≥ 近 24 期最高 × 0.9999
 近 24 期有效期數 < 18 ⇒ NaN（⛔ 不是 False）
 可得性＝期別次月 10 日後的第一個交易日
 ⛔ 不動研究三／十三既有的 rev_hi24 面板
```

### 12-1 做法（⛔ 不重做槽數曲線，接 P1 既有工具）

```

⭐ 那個收斂點是一個【輸出】，不是限制
```

⚠ **P1 的既有結論要帶進來**：N 降則離散度按 1/√N 放大——**方向 ✓、幅度 ✗**
