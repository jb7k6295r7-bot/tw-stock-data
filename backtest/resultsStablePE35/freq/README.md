## 執行者定的讀法（看任何數字前寫死；全文見兩支程式檔頭 ★）

- 「最近 5 個完整財年」用原版的同一 5 年（台股 quality()、美股 ★4 fy_window）；ROE＝年度淨利 ÷ 年底權益（原版口徑），權益 ≤ 0 該年不過。
- 虧損：台股＝歸母淨利 < 0（原版 noloss）；美股＝原版 ★5②（淨利 < 0 且營業利益 ≤ 0）。
- 「EPS 比前一年跌超過 30%」只比 5 年窗內相鄰 4 對；前一年 EPS ≤ 0 ⇒ 不過。另一讀法（連窗首年與前一年比，共 5 對）只在描述欄報家數，不改判。
- 季末本益比：台股＝stocks_per 每個日曆季最後一列的 per（> 0），窗 [評估日−5 年, 評估日)；美股＝原版 ★1／★3 的同一組季末點與算法，窗 [評估日−5 年, 評估日]。「最少 3 年」＝最早一點 ≤ 評估日−3 年（兩邊都照原版中位數的 3 年檢查寫法）。p25 用 numpy 線性內插。
- 任一條不可算 ⇒ 不算穩定溢價（pe_T 照原版 25），筆數照報。
- 財報可用日：台股照 seq352（最早上傳時戳嚴格早於評估日；原版 available()）；美股照原件口徑（first_filed < 評估日）。
- 描述欄乾跑：台股「可算」＝出場日（+250／+750 交易日）在日曆內且原版硬斷點旗標 0；美股＝原版 Holder(dry=True) 窗滿。大盤只查日期覆蓋。⛔ 不讀任何報酬或價格報酬值。
