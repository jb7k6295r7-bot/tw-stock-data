# 交易紀錄檢驗工具說明

一句話：給它一份逐筆交易表，它回答「這是有優勢、像運氣、還是負期望」，並把理由講清楚。

做法參考開源專案「反詐投資王」（mars-tw/anti-gambling-trader-tw，MIT 授權）的檢驗流程；程式是回測線自己寫的（`backtest/tradecheck.py`），沒有抄它的程式碼。

---

## 一、怎麼用

```
cd ~/tw-p17
~/tw-p16/.venv/bin/python -m backtest.tradecheck 我的交易.csv --html 結果.html
~/tw-p16/.venv/bin/python -m backtest.tradecheck --check          # 工具自我查核
```

常用參數：

| 參數 | 意思 | 預設 |
|---|---|---|
| `--frac` | 每筆投入多少資金（算回落、風險情境用） | 0.1（一成） |
| `--loss-x` | 風險情境的虧損門檻 X | 0.2（兩成） |
| `--cost` | 表裡沒有成本欄時的來回成本 | 0.585% |
| `--html`／`--json` | 輸出網頁／完整數字 | 不輸出 |

### 交易表要有哪些欄

一列一筆，第一列是欄名（中英文都認得），`#` 開頭的列當註解。

| 欄 | 必要？ | 說明 |
|---|---|---|
| 代號 | 建議 | |
| 進場日、出場日 | 建議 | 沒有出場日就做不了樣本外、連虧、回落 |
| 進場價、出場價 | 二選一 | 有價格就自己算報酬並扣成本 |
| 報酬 | 二選一 | 已扣成本的淨報酬（0.05 或 5% 都可）；有這欄就直接用 |
| 股數 或 權重 | 選填 | 用來算金額損益、單筆貢獻；顯著性一律用「每筆報酬率」 |
| 成本 | 選填 | 來回成本比率；大於 0.2 當成金額（元） |
| 標籤（或 策略、來源） | 選填 | 分策略描述用 |
| 持有天數 | 選填 | 沒有就用進出場日估 |
| 基準報酬 | 選填 | 同一段時間「隨便買」的報酬；有這欄會另報「超額」 |
| 照規則報酬、實際報酬 | 選填 | 前瞻紀錄的兩欄；也可給「規則出場價、實際出場價」 |

**還沒賣的（沒有出場價、也沒有報酬）⇒ 列為未平倉，不進任何統計。**

## 二、它檢查什麼

1. **基本數字**：筆數、勝率、平均賺、平均賠、盈虧比、期望值（每筆平均淨報酬）、獲利因子、最大連虧、最賺一筆占淨利多少、持有天數。
2. **是不是運氣**：t 檢定＋置中 bootstrap，兩個都 p < 0.05 才算「不像運氣」。
3. **分月重抽**（本專案加的）：同一個月出場的交易會一起漲跌，逐筆當獨立會高估顯著；整月一起重抽再檢一次。
4. **樣本外**：依出場時間切一刀（前約七成、後約三成，兩段各至少 10 筆，同一天出場的不拆開）。兩段都要顯著為正，且後段比前段少不到一半，才算「延續」。筆數不夠就寫「無法驗證」。
5. **賭博特徵**：負期望、單筆暴賺撐場（最賺一筆占淨利一半以上）、賺小賠大（勝率 > 七成但盈虧比 < 0.4）、左偏（報酬偏態 < −1）、安全邊際薄、極端回撤（> 50%）、長連虧（≥ 8 筆，並附「以這個虧損率本來就會出現的機率」）、獲利因子接近 1。
6. **逐標籤**：各標籤只描述；另列「停掉這個標籤，整體會怎樣」。
7. **轉正數字**：期望值為負時，勝率要到多少、或盈虧比要到多少才轉正；已經為正時，改報還可以退到多少。
8. **風險情境**：用自己的報酬重抽，模擬做 N 筆後的最大回落分佈、虧超過 X% 的比例。
9. **超額**（有基準報酬欄時）：把「報酬 − 基準」再跑一次全套。
10. **照規則 vs 實際**（有兩欄時）：實際比規則每筆多賺或少賺多少，這個差是不是運氣。

## 三、五級裁決

由壞到好依序判，先碰到哪一級就停：

| 級 | 什麼情況 | 意思 |
|---|---|---|
| **負期望** | 每筆平均淨報酬 < 0（筆數夠時） | 方法不變，做越多賠越多。這是保守原則：負的就先停，不代表已證明一定輸。 |
| **樣本不足** | 已平倉不到 30 筆 | 再好再壞都還分不出是方法還是運氣。 |
| **像運氣** | 期望值 ≥ 0，但兩個檢定沒有都 < 0.05 | 帳面賺，但和「其實沒優勢、只是剛好」分不開。 |
| **脆弱優勢** | 兩個檢定都過，但有高嚴重度賭博特徵、安全邊際薄、分月重抽不顯著、或樣本外沒延續 | 可能有東西，但結構不穩，不能放大部位。 |
| **統計優勢（仍不是保證）** | 以上全過 | 到目前為止的證據支持正期望。市場會變，優勢會衰減。 |

跟原專案不同的地方：分月重抽不顯著、樣本外沒延續、報酬左偏，在這裡都會把「統計優勢」降成「脆弱優勢」——只會更嚴，不會更鬆。

## 四、哪些話不能說

- ⛔ **p 值不是「有優勢的機率」**。它的意思是：「假如其實沒有優勢，光靠運氣出現這麼好成績的機率」。1 − p 也不是「信心度」。
- ⛔ 「統計優勢」不是「未來會賺」。它只說過去這批交易不像運氣。
- ⛔ 不能拿逐標籤的數字說「某個策略有優勢」：同時看很多標籤，總有幾個會碰巧好看。要認證某一策略，得單獨、事前登錄再測。
- ⛔ 「停掉某標籤後會更好」是事後挑出來的，改善會被高估。
- ⛔ 風險情境是「如果未來像過去」，不是預測；也沒算同時持有好幾檔的重疊。
- ⛔ 只看絕對報酬，**同期大盤漲時隨便買也會被判優勢**（試跑的假訊號就是這樣）。要問「選得比隨便買好嗎」，要看超額。
- ⛔ 「負期望」不是說已證明一定輸，是保守地先停。
- ⛔ 未平倉的單子不能拿來說賺或賠。
- ⛔ 拿**回測交易**跑出「統計優勢」，不等於策略有效：規則若是看過整段歷史才定、或是從很多試過的做法裡挑出來的，工具的樣本外就不是真的沒看過，也沒有算進「試了幾種」。回測的結論仍以事前登錄與裁定為準；這個工具最適合檢驗**前瞻紀錄的實際交易**。

## 五、已知限制

- 兩個檢定都假設每筆交易互相獨立；分月重抽只處理了「同月」這一層。
- 左偏（常小賺、偶爾大賠）的報酬，兩個檢定都偏寬鬆（合成查核：均值 0、100 筆時誤判約 13%）。所以報酬偏態 < −1 會亮高嚴重度警訊，最多給「脆弱優勢」；`--check` 會印出擋下後的誤判率。
- 樣本外只切一刀，不是滾動驗證；而且規則必須在看到後段資料之前就定好，否則後段不算真的沒看過。
- 每筆投入比例（`--frac`）是假設值，回落數字會隨它改變。
- 統計顯著不等於值得做：很小的優勢通過檢定，扣掉心理壓力與實際滑價後未必划算。
