# 上市歷史股數：可行性量測（⛔ 這是量測，不是資料）

**方法**：`股數 ＝ 股本（仟元）× 1000 ÷ 面額`，股本取自 MOPS 資產負債表。

- `bs_hist/` 涵蓋 **46 季**：2015Q1 ~ 2026Q2

## ★★ 歷史驗證（上櫃，46 季逐季對官方發行股數）

上櫃日檔**每天**都有官方發行股數 ⇒ 每一季的季末交易日都是一個外部錨點。
⛔ 面額用 `par_timeline.csv` **按當時**取，不是一律用 10。

- 可比對 **33,007** 個（季, 檔）配對
- **中位數誤差 0.0000%**
- 誤差 < 0.01%：**27,904**（84.5%）
- 誤差 < 0.1%：**29,038**（88.0%）
- 誤差 < 1%：**30,567**（92.6%）
- 誤差 < 5%：**31,729**（96.1%）

⇒ **這條公式在 46 季的歷史上成立**，不是只有今天湊得上。

### ⚠ 殘差的成因：查到一部分，⛔ 沒查完就不寫成查完

- **特別股**：確認至少一例——3095 及成的差額 **+6,180,000 股**，正好等於它的特別股股數。BS 的 `股本` 含特別股，日檔的發行股數不含。
- ⛔ **但特別股解釋不了全部**：2026Q2 誤差 ≥0.5% 的 109 檔裡，**只有 2 檔**的差額對得上快照的特別股欄。
- ⚠ 我試過的另一個假設「差額 ≈ 私募股數」也**不成立**。
- **預收股款（權益項下）之約當發行股數**：解釋 9 檔（股本收了、股票還沒發）。⛔ 「待註銷股本股數」解釋 0 檔。

### ⭐ 剩下的那些，成因**很可能是時點不是季末**

拿 2026Q2 誤差 ≥0.5% 的 **109 檔**，去掃全部 2,847 個日檔，問一句：**有沒有哪一天的官方股數剛好等於推算值？**

```
有某一天對得上：93 檔／109
  其中那一天在季末**之後**：83 檔｜之前：10 檔
```

⇒ 這強烈指向：那張表的 `股本` **不是季末那一刻的值**，而是接近出表當下的值。
⇒ **後果不是誤差，是時點錯位**：把較晚的股本掛在較早的那一季上，序列的形狀會對、日期會偏。

### ⭐⭐ 再往下查，成因有**季節指紋**——每年的 Q2 都是最差的

逐季算「誤差 ≥0.5% 的比例」，46 季排開之後形狀非常清楚：

⇒ **Q2 幾乎年年是其他季的兩倍**（Q2 約 13~19%，其餘約 5~9%）。

**機制**：Q2 財報在 **8 月中**公布，而 8 月正是台股**除權息高峰**。
若表裡的 `股本` 反映的是**公布當下**而不是 6/30，
那 Q2 的股本已經含了股票股利、而 6/30 的股數還沒有
⇒ **Q2 系統性偏高**。實測那些離群檔的差額確實**大多為正**，方向一致。

⚠ 例外：2021Q2 只有 7.6%（那年減資／股票股利特別少？**未查證**）。

⇒ **結論改寫**：這不是「還有 12% 不知道為什麼」，
是**已知的時點錯位，而且知道它什麼時候最嚴重**。
⛔ 但落地前仍要決定：季頻序列的日期要掛「季末」還是「公布日」——
**那是語意決定，不是我的**。
