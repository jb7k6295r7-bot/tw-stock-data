## 推定規則（全文，凍結）
1. **新上櫃名單**：證交所 siis「IRB170 新公司彙總表」上櫃版
   `https://siis.twse.com.tw/publish/otc/<民國年>IRB170_<MM>.HTM`。
   每個資料年月 M 會列出當月新進上櫃的公司，不分來源（興櫃轉、上市轉上櫃、控股公司換股新設、外國企業第一上櫃都會在）。
   - 每頁都要對過表頭「資料年月」等於 M，且「合計：N 家」等於解析出的家數，不符就停。
2. **興櫃名冊**：siis「IRB110 股權異動彙總表」興櫃版（rotc）
   `https://siis.twse.com.tw/publish/rotc/<民國年>IRB110_<MM>.HTM`。
   這是每月的興櫃公司全名冊，一家一列。
   - 每頁都要對過表頭資料年月；如果解析出 0 家就停。
3. **判定**：IRB170 上櫃新公司中，資料年月 M 的公司，只要在興櫃 IRB110 的 **M−3～M** 任一月名冊出現，就判 `inferred=1`（推定興櫃轉上櫃），否則 `inferred=0`。
4. **輔證**：`predeclare_rotc_last` 是內部人事前申報（`curated/insider_predeclare`）在 M 月以前最後一次 market=rotc 的申報日。
   - 只供核對，**不影響判定**。

## 欄位
| 欄 | 意義 |
|---|---|
| stock_id、name | IRB170 原文代號與簡稱（含「F-」「KY」「（第一上櫃）」等官方字樣） |
| irb170_ym | 上櫃新公司的資料年月 M（YYYY-MM） |
| irb170_published | 該期 IRB170 的表頭「日期」（公布日，約次月 17～20 日） |
| inferred | 1＝推定興櫃轉上櫃；0＝不是或核不到 |
| rotc_last_ym | M−3～M 之間最後一次出現在興櫃名冊的月份 |
| rotc_months_in_window | M−3～M 共 4 個月裡，出現在興櫃名冊的月數 |
| rotc_first_ym_seen | 抓取範圍（2005-10 起）內，第一次出現在興櫃名冊的月份 |
| predeclare_rotc_last | 輔證，見上 |

⚠ 事件日（第一個上櫃交易日）**不在這份表裡**，請用日線 `data/stocks/<代號>.csv` 第一列 market=tpex 的日期。
- 2015-02 起推定的 289 檔，在庫裡第一個上櫃交易日都落在 irb170_ym 同月（289／289，0 不符）。
- 另有 8 檔沒核到：2938、7856（2026-09），2249、6604、6825、6898、6938、7806（2026-10）。
  - 原因是本線核對用的本機日檔停在 2026-09 中，這幾檔在那份資料裡還是興櫃列。
  - main 的 stocks.csv 已經是 tpex，所以不是錯。
