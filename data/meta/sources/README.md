- **取得方式**：⚠ **使用者用瀏覽器操作頁面、按「另存CSV」匯出後提供**（2026-09-09 13:23 台北）。
  ⛔ **不是我方程式抓的。** 我方到當天為止對這條路留下六條否定紀錄
  （見 `_tpex_probe.txt`），原因是**這個頁面要執行 js 才會出現內容**，
  而我方環境只有 `urllib`、沒有瀏覽器。

- ⚠ **區間邊界**：這份只涵蓋 2019-09-09 起。**在那之前有沒有事件，這份答不了。**

- **★ 這份 PDF 還回答了一個我方查了 12 條路都沒答出來的問題**，原文照抄：

- **是什麼**：櫃買中心「減資恢復交易參考價」的查詢結果匯出（**cp950 編碼**，
  ⚠ 跟面額變更那份的 Big5 不同，⛔ 不要假設同站同編碼）。
- **查詢區間**：民國 102/09/01 ~ 115/09/21｜**284 筆**（檔案自己宣告「共284筆」）
- **取得方式**：⚠ **使用者用瀏覽器匯出後提供**（2026-09-09 15:36 台北）。
  ⛔ 不是我方程式抓的，理由同上一份：那頁要執行 js。
- **轉檔後**：`data/meta/otc_reduce_reference.csv`（UTF-8、民國年轉西元）。
- **對帳結果**（`reduce_check.py`，同日）：
  逐筆比 `pre_close`／`ref_price` **相符 232、不符 0**；
  減資原因字串 **232/232 一致**；我方上櫃有而官方沒有 **0 筆**。

### ⚠ 這份官方檔自己有一列對不上

    "1070925","6109","亞元","10.50","10.63","11.65","9.57","10.65","0.00","現金減資"
    "1090925","6109","亞元","10.50","10.63","11.65","9.57","10.65","0.00","現金減資"

**六個數字一模一樣，只有民國年不同（107 vs 109）。** 我方資料的證據：
2018-09-25 那次我方有（`pre_close 10.5 → ref 10.63`，且 09-12~09-25 之間確實停止買賣）；
2020-09-25 那天我方價格 **14.45 → 13.95，沒有跳、沒有停牌**。
⇒ `reduce_check.py` 把 `1090925` 列為**已知不一致**並排除，
⛔ 但**不改動這份原始檔**——原始檔的語意是「對方給了什麼」。
⚠ 這是「多筆一致要先問一致的原因是不是共同來源，再問是不是共同錯誤」的實例。
