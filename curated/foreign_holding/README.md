# foreign_holding — 外資及陸資持股統計【月表】

每月最後一個交易日一發，存外資持股水準。⚠ 月底快照，⛔ 不是逐日。

## 範圍（2026-10-21）

| 段 | 期間 | 狀態 |
|---|---|---|
| 一 | 2004-02～2012-12（上櫃 2007-05 起） | ✅ 已入 main（seq533 §二 A） |
| 二 | 2013-01～2024-07 | ✅ 已入 main（裁定 seq424） |
| 三 | 2024-08～2026-09 | ✅ 已建（裁定 seq424）。2026-10-21 第一次抓到 2024-08-30 時 TWSE 回 611 bytes 的 HTML 擋阻頁而停手；解擋後同一支程式接續補完（已抓月份走快取） |
| 之後 | 每月 | `--recent` 排程補上個月（尚未接排程） |

- 依據：台股 seq533 §二 A、裁定 seq424；資料庫線子代理 2026-10-21 建置。
- 產生：
  - `python3 curated/foreign_holding/build.py --start 2013-01 --end 2026-09 [--check --check-months 2016-06,2024-06]`
  - `python3 curated/foreign_holding/build.py --recent [--check]`：⭐ **排程用**，只抓上個月（台北時間）的月底，併入當年檔
  - 原始回應快取在 `~/.cache/foreign_holding/`（⛔ 不進 repo；只在解析與日期驗證都過了才寫，重跑不重打）。
- 寫檔＝**合併、只准變多**：讀現有年檔 → 只替換本趟抓到的 (date, market) → 寫回；其他月份逐字保留。整趟不寫的三種情形：
  ① 某 (date, market) 新列數 < 舊列數；② 年檔總列數變少；③ 新抓那個月的內容與檔裡同市場其他月份**完全相同**（參數回音）。
  ⚠ ③ 只比同一個年檔：1 月那一發不會跟去年 12 月比。
- 當月（還沒過完）一律不抓：日曆裡當月的「最後一天」不是月底。

## 來源（皆官方）

| 上櫃（未收） | MOPS `https://mopsov.twse.com.tw/server-java/t13sa150_otc`，POST `years=YYYY&months=MM&days=DD&bcode=&step=2`（HTML，cp950） | 2004-08-04 | ⛔ **不是全名單**：2008-05-30 有 429 檔、TPEx 有 546 檔（MOPS 那 429 檔全在 TPEx 裡；少掉的 117 檔裡 106 檔外資持股 > 0）；2012-12-28 有 542 檔、TPEx 有 634 檔。兩邊都有的檔約 1.5% 數值不同 ⇒ 本檔不收 |

## 欄位

| 欄 | 說明 |
|---|---|
| date | 資料日（每月最後交易日） |
| market | twse／tpex |
| stock_id, name | 官方原值 |
| isin | 國際證券編碼（只有上市有） |
| issued_shares | 發行股數（股） |
| foreign_avail_shares | 外資（及陸資）尚可投資股數 |
| foreign_shares | 全體外資（及陸資）持有股數 |
| foreign_avail_pct, foreign_pct | 尚可投資比率、持股比率（%） |
| limit_pct | 法令投資上限比率（2010 起上市為「外資及陸資共用」那一欄） |
| china_limit_pct | 陸資法令投資上限比率（2010 起上市才有） |
| change_reason | 上市：與前日異動原因（空白／1～5，定義見官方 notes）；上櫃：備註欄 |
| last_report_date | 最近一次公司申報外資持股異動日期（民國字串；早年官方回 0 ⇒ 空白） |

數字去千分位與 `%`。官方沒有的欄留空。

## 限制

1. 月底快照，月中異動看不到。官方當日盤後公布 ⇒ 當日收盤後可用。
2. 欄名有年代差：2009 前「外資…」、之後「外資及陸資…」；2010 起上市多一欄陸資上限。持股口徑隨法規改變，跨年比較自行注意。
3. `limit_pct` 2004 年上市全部是 `0.00`（官方原值，⛔ 不等於「不可投資」）；2008 起大多 100.00。
4. 母體含 ETF、受益憑證、TDR、早年 4 碼權證（`03xx`～，只到 2005）；用前自行依代號篩。
5. TDR 的持股比率可以 > 100%（9101 福雷電 2008-05/06 100.93%、9151 旺旺 2010-06 102.87%），官方原值，保留。
6. 上櫃 2007-05 之前沒有（官方 TPEx 端點從 2007-05-02 起；MOPS 那支早到 2004-08 但不是全名單）。
