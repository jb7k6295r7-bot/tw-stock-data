# 董監、經理人、10% 大股東：持股水準（IRB110）與質權設定（IRB130）全市場月報，2006-01 起

⭐ 由 `build.py` 抓證交所 siis 靜態月報建成。歷史由 backfill.yml mode=curated 原樣複製到 `data/meta/insider_holding/`；之後每月的新月份由 daily.yml「內部人月報」那步直接補進 `data/meta/insider_holding/`（curated 這份不再更新 ⇒ ⭐ 讀 data/meta 那份）。
依據：回測 1127-1457（單因子 S29 內部人持股增加、S87 董監持股比例水準、S30 內部人質押比上升）；資料庫 1127-1531；裁定 seq526。

## 來源

`https://siis.twse.com.tw/publish/<sii|otc>/<民國年>IRB<110|130>_<MM>.HTM`（cp950；少數月份 UTF-16，程式已處理）

| 檔 | 官方表 | 每家公司一列 |
|---|---|---|
| `irb110_<年>.csv` | IRB110 董事、監察人、經理人及百分之十以上大股東**股權異動**彙總表（不含金控子公司） | ✅ 全名單 |
| `irb130_<年>.csv` | IRB130 董事、監察人、經理人及百分之十以上大股東**質權設定**彙總表（不含金控子公司） | ✅ 全名單 |

⭐ 跟 `insider_monthly/`（IRB140／190／200，只收 ≥100 萬股的**事件**）不同：這兩張是**每家公司每月一列的水準值**。

## 欄位（股數單位＝股、比率單位＝%；數字已去千分位）

共同：`data_ym`（資料年月，西元）、`published`（⭐ 檔頭「資料日期」＝發布日）、`market`（sii＝上市／otc＝上櫃）、`stock_id`（公司欄前 4 碼）、`company`（官方公司欄原字串，名稱被截斷）。

IRB110：

| 欄 | 官方欄 |
|---|---|
| issued_shares | 實際發行股票總額 |
| ds_increase／ds_decrease | 董事、監察人本月份增加股數／減少股數 |
| ds_shares | 董事、監察人本月份實際持有股數 |
| ds_pct_of_issued | 董監持股佔股份總額 %（官方四捨五入到 0.01） |
| mgr_shares | 經理人本月份實際持有股數 |
| major_shares | 百分之十以上大股東本月份實際持有股數 |

IRB130：

| 欄 | 官方欄 |
|---|---|
| ds_shares | 董事、監察人本月份實際持有股數 |
| ds_pledge_set／ds_pledge_release | 董監本月份設定股數／解除股數 |
| ds_pledged_cum | 董監累計設定股數 |
| ds_pledged_pct | 董監佔持股比例 %（＝累計設定 ÷ 實際持有） |
| mgr_shares／major_shares | 經理人／10% 大股東實際持有股數 |
| mgr_major_pledged | 經理人及 10% 大股東已設定股數 |
| mgr_major_pledged_pct | 經理人及 10% 大股東佔持股比例 % |

## ⚠ 用之前

- ⭐ **可用日用 `published`**（例：2025-08 那份 2025-09-17 才發布，約晚 3～7 週），⛔ 不可用 `data_ym`（裁定 seq526 §四、seq352 精神）。
- 「董監」是董事＋監察人合計（含法人董事與其代表人的持股口徑依官方）；經理人、10% 大股東**分欄**，⛔ 不要自己相加當「內部人」而不註明。
- 不含金控子公司（官方表名就這樣寫）。
- `stock_id` 取公司欄前 4 碼：名稱以數字開頭的公司（6741 91APP）照前 4 碼取；用之前以 `company` 核對。
- 公司欄名稱被官方截斷、且早年與近年寫法不同（「台灣水泥」→「臺灣水泥股份有限」），⛔ 不要用名稱當鍵。
- 少數早年上櫃檔的冷僻字解不出來（顯示亂碼），只影響 `company`，數字欄不受影響。

- ⚠ 官方原檔偶有打錯，**原值照存、不改**：已知 6945 圓祥生技 2026-06 `issued_shares`＝9,720,216（前後月 85,573,410／97,531,160，佔比 27.64% 與 9 千 7 百萬股相符）⇒ 用發行股數自己算比例的，先跟前後月比。
- ⚠ 官方原檔有壞標籤：截斷的公司名稱後面 `</TD>` 被寫成 `?/TD>`（1626 艾美特 2016-03～2017-11、4107 邦特 2009-01～2010-01）⇒ 程式已修回，數字欄不受影響。

## 範圍與驗算（2026-11-28 建置，2006-01～2026-10）

- 上市、上櫃各 **250 個月**，兩表都齊；每月家數上市 678～1,088、上櫃 508～898；合計各 391,650 列；同月同代號 0 重複。
- 發布日－資料月底：16～31 天（中位 20）。
- `ds_pct_of_issued` ＝ ds_shares ÷ issued_shares（容差 0.011）：不符 1／391,650（即上面 6945 那筆）。
- `ds_pledged_pct` ＝ ds_pledged_cum ÷ ds_shares：不符 0。
- IRB110 與 IRB130 同月同公司的董監實際持有股數：391,650 列**逐列相同**。
- IRB190（董監 ≥100 萬股質權設定事件，`insider_monthly/`）同公司同月加總 ≤ 本表 `ds_pledge_set`：5,765／5,765 成立。
- 2330 2026-10：issued_shares 25,932,370,067。
