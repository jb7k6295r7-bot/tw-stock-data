# 幣本位永續資金費率：封存以前那段（REST 補）

⭐ 由 backfill.yml mode=curated 原樣複製到 `data/meta/crypto_cm_funding_rest/`。起因：加密 C10 §十①（裁定 seq289 §四）。

## 為什麼要另外一份

- 主檔 `data/crypto_cm_funding/<SYM>USD_PERP.csv` 來自 data.binance.vision 月封存（crypto.yml mode=cm）。
- ⚠ 幣本位資金費率的月封存【從 2022-07 才有】（2022-06 以前逐月 404，2026-10-04 實測）。
- 2022-07 以前用官方 REST `dapi.binance.com/dapi/v1/fundingRate` 補；⛔ 這個端點從 GitHub Actions 回 451 ⇒ 只能本機跑一次、手工落檔（build.py）。

## 檔案

`<SYM>USD_PERP.csv`（BTC、ETH、BNB、SOL、XRP、DOGE）：funding_time,funding_rate,rate_type（官方欄位原樣，毫秒 UTC）
區間：各幣上市日 ～ 2026-10-04 00:00 UTC（2022-07 起與封存重疊，逐筆對帳）

## 怎麼用（給使用者）

⭐ 研究直接用【本檔】全期（完整版）；主檔 data/crypto_cm_funding 只當對照。⚠ REST 時戳偶有幾毫秒尾數（例 1630569600007），比對時以秒對齊。

## 驗收

區間已改為各幣上市日 ～ 2026-10-04 00:00 UTC（REST 全期）——因為主檔（封存）有兩個問題：
- ⚠ 封存【每個月都缺月底那一天】（2022-07～2026-06 共 47 個月 × 3 筆；USDT 合約的資金費封存沒有這個問題）
- ⚠ 封存落後：2026-07、08 月檔尚未發布
⇒ ⭐ 研究用【本檔】當資金費率的完整版本；主檔留作對照。
