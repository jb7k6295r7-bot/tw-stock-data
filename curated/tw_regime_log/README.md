## 一、來源原則

- 每一列只採官方出處：金管會（含證期局）新聞稿／令、證交所新聞稿／規章、櫃買中心公告、全國法規資料庫，以及金管會出版的月刊與文件。媒體報導不當出處；只有媒體來源的列，標「待查證」。
- 日期分三欄，各寫各的：
  - `announce_date`：公告、發布或公布日。法律用總統令公布日，令用發文日。
  - `effective_date`：生效或施行日。
  - `end_date`：只有暫時措施才填，寫官方說的「停止適用」或「回復」那一天。
  - 查不到的欄位留空，不用推的補。
- 有多個出處時，`source_url` 用「 ; 」隔開。證交所新聞用官方 JSON 端點 `twse.com.tw/rwd/zh/news/newsDetail?id=…`（網頁版是 JS 渲染，抓不到內文）；2021 年之後多數新聞的內文是 PDF，網址另外列出。
- `market`：
  - 官方稿寫明「上市（櫃）」，或金管會層級的措施，標 both。
  - 只有證交所出處的，標 twse；櫃買是否同步沒有另外查，有提到的寫在 note。
- 查證日：2026-10-09。抓取方式：程式每發間隔 3.5 秒以上、一般瀏覽器 UA、沒碰驗證碼。
