# ndc_signal — 國發會景氣指標與景氣對策信號（月頻）

> ⚠⚠ **修正後資料、非當時公布值** ⚠⚠ —— 只供描述，⛔ 不可直接當回測訊號（會有前視）。

- 依據：台股 seq533 §二 B；資料庫線子代理 2026-10-21 建置。
- 產生：`python3 curated/ndc_signal/build.py`（一發 metadata＋一發 ZIP；ZIP 只在記憶體讀）。

## 來源

| 項目 | 內容 |
|---|---|
| 資料集 | 政府資料開放平臺 data.gov.tw **6099「景氣指標及燈號」**（國家發展委員會） |
| metadata | `https://data.gov.tw/api/v2/rest/dataset/6099` → `distribution[].resourceDownloadUrl` |
| 檔案 | `https://ws.ndc.gov.tw/Download.ashx?u=…&n=…`（ZIP：景氣指標與燈號、景氣對策信號／領先／同時／落後指標構成項目 共 5 個 CSV＋schema） |
| 官方說明（逐字） | 「每月發布時回溯修正領先、同時及落後指標的歷史資料。」 |

本檔只取 `景氣指標與燈號.csv`。構成項目四檔（各指標的原始成分序列）沒收，要再加。

## 欄位

| 欄 | 說明 |
|---|---|
| period | YYYY-MM（官方 Date 欄 YYYYMM） |
| leading_index／leading_detrended | 領先指標綜合指數／不含趨勢指數 |
| coincident_index／coincident_detrended | 同時指標綜合指數／不含趨勢指數 |
| lagging_index／lagging_detrended | 落後指標綜合指數／不含趨勢指數 |
| signal_score | 景氣對策信號綜合分數（官方 `-` ⇒ 空白，⛔ 不是 0） |
| signal_light | 景氣對策信號（官方原字：紅／黃紅／綠／黃藍／藍） |
| vintage | ZIP 內 `景氣指標與燈號.csv` 的檔案時間＝這一版的修訂時點 |

## 2026-10-21 建置結果

- 536 期 1982-01～2026-08；有燈號 512 期 1984-01～2026-08；vintage 2026-09-29 11:44。
- 各燈號分數範圍：紅 38～42（40 期）、黃紅 32～37（69）、綠 23～31（192）、黃藍 17～22（129）、藍 9～16（82）。
  ⚠ 四十年的分數與燈號**完全照現行門檻切開、零重疊**，看起來是用現行方法回算過的整條序列，
  ⇒ 又一個「這是修正後的版本」的跡象。早年當時公布的燈號可能用不同的門檻或項目，⛔ 不能拿這份去推「當年看到的是什麼燈」。

## 限制

1. ⛔ **不是當時公布值**。每月發布時，領先、同時、落後指標的歷史都會被回溯修正；燈號分數也會跟著構成項目修正。
   - 當時公布值只在國發會每月的「景氣概況」新聞稿（PDF）裡（國發會網站新聞稿，以及景氣指標查詢系統 index.ndc.gov.tw 的「新聞稿」頁 `/n/zh_tw/data/news`）。⛔ 本檔不抓 PDF。
   - ⚠ 2026-10-21 本線打 `index.ndc.gov.tw` 先 200、後來連續 403（`/n/json/data/eco/indicators` 要 CSRF；之後頁面也 403）⇒ 已停手，**新聞稿頁的實際形狀沒有驗**。
2. 要做回測時，需要「每月一份 vintage」：從本檔建置日起每月重跑並另存，或之後補新聞稿 PDF 的當時值。
3. 月頻，下個月下旬公布（例如 2026-08 期在 2026-09 底公布）⇒ 可用日不早於公布日，⛔ 不可用期末日。
