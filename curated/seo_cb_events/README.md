# 現金增資決議／可轉換公司債發行決議 事件表 1999～2026-10-20

⭐ 由 `build.py` 從公開庫 `data/mops/news/<年>.csv`（MOPS 重大訊息主旨）分類而成；由 backfill.yml mode=curated 原樣複製到 `data/meta/seo_cb_events/`。
依據：裁定 seq399 §四.1（用 news 主旨做事件表；現增決議／可轉債發行決議兩類、含已下市；濾雜訊規則先寫死再跑；交件附規則與隨機 50 則人工核對）。

## 檔與欄

`seo_cb_events.csv`，一事件一列：

| 欄 | 意義 |
|---|---|
| date, time | 重訊發布日、時（⚠ 盤後發布的事件，可交易日是次一交易日） |
| stock_id, name, market | 代號、名稱、sii 上市／otc 上櫃（只收這兩個市場） |
| class | seo＝現金增資決議；cb＝可轉換公司債發行決議 |
| private | 1＝私募 |
| overseas | 1＝海外可轉債（只用在 cb） |
| ipo | 1＝上市櫃前承銷用的現增（初次上市櫃、掛牌前、公開承銷…）⛔ 不是已上市公司的現增，事件研究要排除 |
| subject | 重訊主旨原文 |
| serial | 重訊序號 |

`sample50.csv`：人工核對用的隨機 50 則（seed 20261021）。

## 規則（2026-10-20 寫死；全文在 build.py 開頭）

- 主旨先去掉所有空白；必含「決議」。
- 共同排除：子公司、孫公司、轉投資、被投資、認購、參與、更正、補正、補充、變更、不繼續、撤銷、取消、停止、延後、終止、修正、修訂、更新、資金運用、用途、進度、買回、發行價格、訂價、定價。
- seo：含「現金增資」或「現增」；排除盈餘轉增資、公積轉增資、員工酬勞；只講基準日的排除。
- cb：含「轉換公司債」且含 發行／募集／辦理；排除轉換價格、賣回、贖回、重設、停止轉換、發行條件。
- 同一代號、同一 class，30 個日曆天內只留第一則。

## 範圍與筆數

- 去重後 7,363 筆：sii 3,831、otc 3,532。
  - seo 4,576（一般 2,878、私募 1,121、上市櫃前承銷 577）
  - cb 2,787（一般 2,129、私募 288、海外 269、海外私募 101）
- 含已下市公司：有 57 個代號不在現行 `data/meta/stocks.csv`（多半是 2015 年前下市的）。

## 人工核對

- 第一輪 50 則：4 則誤收、6 則是上市櫃前承銷 ⇒ v2 加排除詞並加 ipo 旗標。
- 第二輪另抽 50 則：47 則對（94%）。錯的是 6642「修訂現金增資案」，以及 3169「股票上櫃辦理現金增資」漏標 ipo ⇒ v3 修正。
- ⚠ 已知殘留：「決議訂定…私募現金增資之事宜」（訂定細節，不是新案）仍會收，例 2537 2008-03-12。

## ⛔ 限制

- 事件層只有日期與代號；金額、價格要讀重訊內文，已下市公司讀不到 ⇒ 用到內文欄位的分析要標存活者偏差。
- 「決議」日是董事會決議日，不是主管機關申報生效日，也不是發行日。
