# 私募明細表（MOPS 私募專區）＋E3 對照

⭐ 由 `build.py` 抓公開資訊觀測站「私募專區—辦理私募有價證券一覽表」`mopsov.twse.com.tw/mops/web/ajax_t116sb01`，解析成一案一列。
依據：協調者 2026-10-22 派工（台股策略線 seq3 會用到）。前置探針（21 發）的紀錄在 `curated/takeover_events/README.md`。

## 檔

- `placement_detail.csv`：一案一列。範圍是 E3 裡 2011 年起出現的公司，列出它們在私募專區的全部案件。
- `e3_placement_match.csv`：`takeover_events.csv` 的每一列 E3，配上同公司「最近的前一個決議日」那一案。

## 抓法（2026-10-22 寫死；全文在 build.py 開頭）

- **一覽**：step=1，每家打一發，回該公司全部私募案。第 4 欄按鈕帶 report_type、決議日、stock_kind。
  - 一覽回 0 列時，改用另一個市場別（上市／上櫃互換）再打一發。
- **明細**：step=2。只抓新式表，也就是 report_type ≠ "1" 的案：
  - "1_1"：普通股、特別股適用
  - "2_1"：公司債、轉換公司債等適用
  - ⛔ report_type="1" 是 2010 年以前的舊表，只有文字、沒有是／否欄，只列出、不抓明細。
- **節流**：每發間隔 ≥4.5 秒，一般瀏覽器 UA。
- **快取**：放在 repo 外的 `~/.cache/placement/{list,detail}/`，有快取就不再打，可中斷續跑。
- **防回音**（每發都驗）：
  - 一覽：每列代號要等於送出的代號。
  - 明細：「公司代號」和「董事會決議日期」要等於送出的參數，不符的存成 `.echobad.html`；超過 5 發不符就停。
- **擋阻**：遇擋阻頁、驗證碼、查詢過量就停（exit 3），不繞過。
  - 判定條件是頁面出現關鍵字、而且沒有「公司代號」，因為有些正常明細的內文本身就含「安全性考量」等字。
- ⚠ mopsov 的 robots.txt 是 disallow。本程式只在本機手動跑，量小、有間隔。

## 欄（placement_detail.csv）

⛔ 不收應募人姓名、法人名稱、前十大股東。

| 欄 | 意義 |
|---|---|
| stock_id, decide_date | 代號、明細的董事會決議日（ISO；舊表是股東會決議日） |
| report_type, stock_kind | 表單類型（1 舊表／1_1／2_1…）、一覽的證券種類代碼 |
| sec_kind, is_bond | 一覽的證券種類原文（普通股／國內轉換公司債…）；含「公司債」＝1 |
| form_title | 明細抬頭括號內（例「私募普通股適用」） |
| is_insider | 應募人是否含有公司內部人或關係人：1／0／空（都沒勾或舊表） |
| is_strategic | 應募人是否為策略性投資人：1／0／空 |
| control_change | 經營權是否重大變動：1／0／空。舊問法是「私募前一年內…或引進策略性投資人後是否將造成…」；2025 年前後改成「前一年內至交付日起一年內是否發生…」，兩種都收 |
| non_cash | 應募人是否擬以非現金方式出資 |
| indep_objection | 獨立董事反對或保留意見：1／0／na（不適用） |
| price_floor_pct | 私募價格不得低於參考價格（公司債是理論價格）之成數 % |
| fs_period, nav_ps, net_income_k, accum_pl_k, close_prev | 最近期財報年季（民國 YYY/Q）、每股淨值、最近年度稅後損益與累計盈虧（千元）、決議日前一日收盤價 |
| report_date, first_confirm_date | 申報日期、第一次確認日期 |
| echo_ok, fetched | 防回音結果、快取檔名 |

## E3 對照規則（寫死）

- 同代號的私募案中，取決議日 ≤ E3 日期、且相差 ≤ 365 天的最近一個決議日；沒有就算未配到。
- 同一決議日有多案（例如 6558 109/10/05 同時有普通股和轉換公司債）時：
  - bond_flag：任一案是公司債就＝1。
  - 三個是／否欄：取股權案，沒有股權案才取公司債案。
  - n_cases：同日的案數。
- gap_days：E3 日期減決議日。0～3 天多半是同一份公告；更大的多半是同一案的後續公告（例如 1795 2019-01-28 引進富士製藥，配到 107/12/10 那一案）。

## ⛔ 限制

- **2010 年以前只有舊表**，沒有是／否欄。舊表的決議日是股東會決議日，晚於董事會公告，所以 2010 年以前的 E3 多半配不到。
- **E3 主旨寫的證券種類可能和內文不同**。例：6558 2020-12-24 主旨是私募普通股引進策略投資人，那一案其實是轉換公司債。⇒ 要用這裡的 bond_flag。
- **私募專區不一定每次董事會決議都有一列**：同一案的修正、補充會更新在原案上，不會另開一案。
